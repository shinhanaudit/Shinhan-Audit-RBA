# FSS 감사 체크리스트 하네스 - 설치 가이드

금융감독원(금감원) 공식 자료를 자동으로 모아 감사 체크리스트를 만들어주는 도구입니다.
개발 경험이 없어도 아래 순서대로 따라 하면 됩니다. 총 3단계입니다.
---

## 1단계: 이 프로그램이 쓸 패키지 설치하기

1. 이 폴더(`thanks`) 안의 **`install.bat`** 파일을 더블클릭합니다.
2. 검은 창이 뜨고 자동으로 설치가 진행됩니다. "설치 완료"라는 메시지가 뜨면 성공입니다.
3. 만약 "Python이 설치되어 있지 않습니다"라는 메시지가 뜨면:
   - https://www.python.org/downloads/ 접속 → 최신 버전 다운로드 → 설치
   - **설치 화면 맨 아래 "Add python.exe to PATH" 체크박스를 반드시 체크**하고 설치
   - 설치가 끝나면 `install.bat`을 다시 더블클릭

---

## 2단계: Claude Code 설치하고 이 폴더 열기

이 도구는 Claude Code(터미널에서 쓰는 AI 어시스턴트) 위에서 동작합니다.

1. https://claude.com/claude-code 에서 설치 안내를 따라 Claude Code를 설치합니다.
2. Claude Code를 실행한 뒤, 이 폴더(`thanks` 폴더 전체)를 작업 폴더로 열어줍니다.
   - 터미널에서 이 폴더로 이동한 뒤 `claude`라고 입력하면 됩니다.
3. 정상적으로 열리면 이 폴더의 `CLAUDE.md`에 적힌 내용을 Claude Code가 자동으로 읽어들입니다. 별도 설정은 필요 없습니다.

---

## 3단계: 본인 Gmail 계정 연결하기 (메일 발송 기능을 쓰려는 경우에만)

체크리스트를 완성한 뒤 "메일로 보내줘"라고 하면 Gmail 초안을 만들어주는 기능이 있습니다. 이 기능을 쓰려면 **본인의 Gmail 계정을 본인의 Claude 계정에 연결**해야 합니다. (코드나 파일 설정이 아니라 Claude 계정 자체의 설정입니다.)

1. https://claude.ai 에 로그인 → 오른쪽 위 프로필 → **설정(Settings)** → **커넥터(Connectors)**
2. 목록에서 **Gmail**을 찾아 **연결(Connect)** 클릭
3. 본인 구글 계정으로 로그인하고 권한을 허용합니다.
4. 연결이 끝나면 Claude Code에서도 자동으로 그 계정의 Gmail을 사용합니다. 다른 사람과 계정을 공유하지 않아도, 각자 본인 컴퓨터에서 이 3단계만 한 번 해두면 각자의 메일함으로 초안이 생성됩니다.

> Gmail 커넥터는 **초안(draft) 생성까지만** 가능합니다. 실제 발송은 지원하지 않으므로, Gmail에서 내용을 확인한 뒤 직접 눌러서 보내야 합니다.

---

## 사용 시작하기

3단계를 모두 마쳤다면 Claude Code 창에 이렇게 입력하면 됩니다:

```
26년 3월 신한은행 감사업무 시작
```

또는

```
종합감사 시작해보자
```

이후 기관명/업권/감사기간을 물어보면 답변해주시면 자동으로 진행됩니다.

---

## 문제가 생겼을 때

- `install.bat` 실행 시 아무 반응이 없다면: 파일을 마우스 오른쪽 클릭 → "관리자 권한으로 실행"을 시도해보세요.
- 패키지 설치가 계속 실패한다면: 사내망 방화벽/프록시가 pip 설치를 막고 있을 수 있습니다. IT 담당자에게 "pypi.org 접근 허용"을 요청하세요.
- 그 외 오류가 나면 검은 창(터미널)에 뜬 오류 메시지 전체를 복사해서 관리자에게 전달해주세요.
